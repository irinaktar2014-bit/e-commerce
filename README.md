## Project Overview 
This project analyzes an e-commerce dataset using MySQL to answer key business questions related to sales performance, customer behavior, product categories, and regional trends.
The goal of this project is to demonstrate SQL skills including:
* Data exploration
* Aggregations
* Joins
* Business-focused analysis

## Dataset
This project uses the Brazilian E-Commerce Public Dataset by Olist(from Kaggle).

## Dataset source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
Due to GitHub file size limitations, raw CSV files are not uploaded to this repository.

## Tables used:
* olist_customers_dataset
* olist_orders_dataset
* olist_order_items_dataset
* olist_products_dataset

## Tools & Technologies
* MySQL(MySQL Workbench)
* SQL(joins, aggregation, filtering)

## Analysis Questions
The following business questions were explored:
1. Which customer states have the highest number of orders?
2. Which product categories generate the highest revenue?
3. How does revenue vary?
